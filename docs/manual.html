공통 · 모든 사용자

로그인하고 화면을 이해하기

역할과 상관없이 처음 알아둘 것들입니다. 아래 용어와 규칙은 모든 화면에서 똑같이 적용됩니다.

로그인

로그인 화면
  1. 아이디와 비밀번호를 입력하고 로그인을 누릅니다.
  2. 처음 가입한 계정은 승인대기 상태입니다. 마스터가 활성화한 뒤에 로그인할 수 있습니다.
  3. 비밀번호를 잊었다면 마스터에게 초기화를 요청하세요.
비밀번호는 4자 이상입니다.

회원가입

로그인 화면›회원가입
  1. 아이디(3~30자, 영문 · 숫자 · . _ -), 이름, 비밀번호(4자 이상)를 입력합니다.
  2. 가입 신청을 누르면 승인대기 상태로 등록됩니다.
  3. 마스터가 계정을 활성화하면 로그인할 수 있습니다.

화면 구성

  • 상단 왼쪽 — 역할에 따라 달라지는 메뉴.
  • 상단 오른쪽 — 역할 배지 · 이름 · 로그아웃.
  • 본문 — 선택한 메뉴의 화면.

알아두기 — 용어와 규칙

연차 종류
연차 1일 · 오전 반차 / 오후 반차 0.5일 · 병가 · 공가. 병가와 공가는 사용일수만 기록하고 연차에서 차감되지 않습니다 (공가 = 공적 사유의 인정 결근).
근무일 계산
연차 일수는 월~금에서 대한민국 공휴일을 뺀 날로 계산합니다. 예를 들어 추석 연휴가 낀 기간에 연차를 내면 공휴일만큼은 차감되지 않습니다. 공휴일은 메인 달력에 빨간색 날짜로 표시됩니다.
잔여연차 계산
가용연차 − (승인된 연차 · 반차 합계 + 마스터 수동 조정). 병가 · 공가는 차감하지 않습니다.
신청 상태
대기 → 승인 / 반려 / 취소. 승인만 연차에 반영되고, 반려 · 취소는 반영되지 않습니다.
날짜 표기
2026-09-02 (수) 형식으로 표시됩니다.

연차를 신청하고 내 현황 보기

연차를 등록하고, 대기 중인 신청을 철회하고, 내 잔여 연차를 확인합니다.

메뉴메인 · 연차 등록

메인 — 캘린더와 내 현황

메인
  • 월별 캘린더에는 전 직원의 연차가 함께 표시됩니다.
  • 연 · 월 드롭다운, ‹ ›, 이번 달 버튼으로 달을 옮깁니다.
  • 모바일에서는 점이 찍힌 미니 달력에서 날짜를 누르면 그 날의 목록이 열립니다.
  • 캘린더 아래 내 연차 현황에는 본인의 가용 · 사용 · 잔여만 나옵니다.
  • 대한민국 공휴일은 날짜가 빨간색으로 표시됩니다.
승인된 연차 병가 공가 승인 대기 * 공휴일

연차 등록

연차 등록
  1. 종류를 고릅니다 — 연차 / 오전 반차 / 오후 반차 / 병가 / 공가.
  2. 시작일과 종료일을 선택합니다. 반차는 하루만 신청되어 종료일이 자동으로 맞춰집니다.
  3. 신청 일수가 미리 표시됩니다. 필요하면 사유(200자)를 적습니다.
  4. 연차 신청을 누르면 대기 상태로 접수되고 팀장 승인을 기다립니다.
주의 — 선택한 기간에 근무일(주말 · 공휴일 제외)이 없으면 신청할 수 없습니다. 신청 일수에서 공휴일이 빠지면 미리보기에 공휴일 N일 제외로 표시됩니다.
기간이 겹치는 본인 신청(대기 · 승인)이 있으면 신청할 수 없습니다. 단, 같은 날 오전 반차 + 오후 반차는 함께 신청할 수 있습니다.

신청 철회

연차 등록›내 신청 내역
  1. 내 신청 내역에서 대기 상태인 신청을 찾습니다.
  2. 철회를 누릅니다.
이미 승인 · 반려 · 취소된 신청은 철회할 수 없습니다. 승인된 연차를 되돌리려면 팀장에게 취소를 요청하세요.
팀장

연차를 승인하고 월별 현황 관리하기

사용자의 모든 기능에 더해, 신청을 승인 · 반려 · 취소하고 월별 연차현황을 조회 · 다운로드합니다.

메뉴메인 · 연차 등록 · 승인 · 연차현황

승인 대기 확인 (로그인 시 알람)

메인
  • 처리할 신청이 있으면 메인 상단에 주황색 배너가 뜹니다 — "승인 대기 중인 연차 신청이 N건 있습니다".
  • 승인 메뉴 옆의 빨간 숫자가 남은 대기 건수입니다.
  • 메인 하단 현황표에서는 전 직원의 연차 현황을 볼 수 있습니다.

승인 처리

승인
  1. 상태 탭에서 대기를 선택합니다. 승인 / 반려 / 취소 탭에서 지난 처리 내역도 볼 수 있습니다.
  2. 필요하면 종류 필터로 좁힙니다 — 전체 / 연차 / 오전 반차 / 오후 반차 / 병가 / 공가.
  3. 각 신청에 메모(선택)를 적고 승인 · 반려 · 취소 중 하나를 누릅니다. 이미 승인된 건은 취소만 가능합니다.
본인이 낸 신청도 직접 처리할 수 있습니다.
주의 — 승인해야 연차에 반영됩니다. 반려 · 취소는 반영되지 않습니다.

월별 연차현황 & 엑셀 다운로드

연차현황
  1. 연 · 월 드롭다운으로 조회할 달을 고릅니다.
  2. 그 달에 승인된 연차가 하루 단위로 표시됩니다 — 이름 · 일자 · 종류 · 사용일수 (연차 · 병가 · 공가 1, 반차 0.5). 주말과 공휴일은 빠집니다.
  3. 엑셀(CSV) 다운로드를 누르면 연차현황_2026-09.csv 파일이 저장됩니다. 엑셀에서 바로 열리고 한글도 깨지지 않습니다.
예시 한 줄 — 김팀장 · 2026-09-15 · 오전반차 · 0.5. 마스터는 이 목록에 나타나지 않습니다.
마스터

계정 관리 · 연차 대리 등록

마스터는 본인 연차를 쓰지 않습니다 — 캘린더 · 현황표 · 연차현황에 마스터 본인은 나오지 않습니다. 대신 다른 사용자의 연차를 대신 등록할 수 있습니다. 승인과 연차현황 사용법은 팀장과 같습니다.

메뉴메인 · 연차 등록 · 승인 · 연차현황 · 연차설정

연차 대리 등록

연차 등록
  1. 대상자를 선택합니다 (사용자 · 팀장). 선택하면 그 사람의 연차 현황과 신청 내역이 함께 표시됩니다.
  2. 종류 · 기간 · 사유를 입력하고 (이름) 연차 등록을 누릅니다.
  3. 등록 즉시 승인 상태로 반영됩니다 (처리 메모: "마스터 대리 등록"). 대상자는 이 건을 철회할 수 없으며, 되돌리려면 승인 화면에서 취소합니다.

계정 승인

연차설정›계정 목록
  1. 계정 목록에서 승인대기(강조 표시)된 계정을 확인합니다.
  2. 승인을 누르면 즉시 활성화되어 로그인할 수 있습니다.

계정 생성

연차설정›계정 생성
  1. 아이디 · 이름 · 초기 비밀번호(4자 이상) · 역할 · 올해 가용연차를 입력합니다.
  2. 계정 생성을 누르면 바로 활성 상태로 만들어집니다.
  3. 초기 비밀번호를 본인에게 직접 전달하세요.

계정 상세 관리

연차설정›(계정) 상세
계정 정보
이름 · 역할 · 상태(활성 / 승인대기 / 비활성)를 변경합니다.
비밀번호 초기화
새 비밀번호를 설정하고 본인에게 직접 전달합니다.
연차 설정
연도별 가용연차와 사용 조정(+/- 수동 가감)을 저장합니다. 사용연차 = 승인된 연차 · 반차 합계 + 사용 조정.
신청 내역
해당 사용자의 최근 신청 기록을 확인합니다.
주의 — 활성 마스터는 최소 1명 있어야 합니다. 마지막 마스터는 역할 변경 · 비활성이 되지 않습니다.
